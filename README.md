# 💰 FinanceTracker

Aplicación móvil de gestión financiera personal con dashboard interactivo, control de metas y deudas, y notificaciones inteligentes vía SMS.

## Estado del Proyecto

**Fase actual:** Fase 0 - Setup y Configuración ✅

## Características Planificadas

- CRUD de transacciones (ingresos y gastos)
- Dashboard con gráficos interactivos
- Metas de ahorro con seguimiento
- Control de deudas con calculadora de pagos
- Notificaciones SMS (Twilio)
- Analytics avanzados y reportes

## Stack Tecnológico

**Backend:** NestJS + PostgreSQL + TypeORM  
**Frontend:** Ionic + Angular  
**Mobile:** Capacitor (iOS + Android)  
**Notificaciones:** Twilio SMS

## Documentación

Ver carpeta `/docs` para documentación completa del proyecto.

## Setup Local
```bash
# Clonar repositorio
git clone https://github.com/JoseDanielZ/finance-tracker.git
cd finance-tracker

# Iniciar servicios Docker
docker-compose up -d
```
